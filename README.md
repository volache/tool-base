# 工具基地：可驗證的積木世界原型

中央是一般 HTML / CSS 工具入口，背景是 Three.js 即時渲染。恐龍、積木地景、雲與圖示都由程式建立，不使用生成圖片充當 3D 場景。

## 本機開啟

已安裝 Node.js 的電腦，在此資料夾執行：

```powershell
node preview.mjs
```

用瀏覽器開啟 http://127.0.0.1:4173 。按 Ctrl+C 停止。無須 npm install，也無須外部 CDN。請透過 HTTP 預覽，不要直接雙擊 dist/index.html，瀏覽器會限制本機 ES module。

## 可驗證的內容

- 六個大方塊入口：滑鼠、觸控與鍵盤皆可操作。
- 搜尋名稱、中文用途與英文關鍵字；Ctrl / ⌘ + K 聚焦搜尋，Enter 或 Google 按鈕會另開 Google 查詢。
- 目前六個工具均為範例，點擊會明確顯示尚未串接。沒有真的轉檔、查詢或提交資料。
- 右下角積木恐龍：斜向前方原地跑，擺腿、擺臂、尾巴與身體起伏。
- 地景斜向恐龍後方循環，草原、沙漠、海岸、雪地、森林與城市可立即切換。
- 右上角月亮 / 太陽切換白天、黑夜：場景光線、月亮星空與介面一起變化，並在同一瀏覽器記住選擇。
- 遠方移除方塊山；雲改為連續的柔邊輪廓。恐龍增加腹板、鼻孔、腳趾與組裝線條，仍採積木造型。
- 暫停 / 播放；設定可選均衡、精緻、輕量，以及每 30 秒自動輪換環境。
- 設定中的驗證資訊顯示實際 FPS、繪製呼叫與三角形數量；背景分頁會停止動畫。
- 系統要求減少動態時，預設停止動畫；無 WebGL2 時工具入口仍可操作。
- 手機改為兩欄，內容可垂直捲動；桌面維持三欄。

## 接上實際工具

編輯 dist/tools.js 的名稱、描述、關鍵字及 url。將 null 改為實際內部 HTTPS 網址後，方塊會成為另開分頁的真實連結。不要在前端檔案內放密碼或存取權杖。

## 檔案

- dist/index.html、dist/styles.css：語意結構、設定介面、積木卡片與響應式排版。
- dist/app.js：搜尋、視窗、場景控制及 3D 失敗時的替代狀態。
- dist/tools.js：可替換的工具目錄。
- dist/world.js：Three.js 場景、恐龍、環境循環、3D 圖示與畫質控制。
- dist/forest-world.js、snow-world.js、sun-world.js、day-life.js、tumbleweed.js、volumetric-fog.js：各環境與氛圍效果。
- dist/weather.js、weather-world.js、rainbow.js：天氣資料（抓取、驗證、快取、三日預報、雨後判斷）、天氣畫面（雨、雪、雲、閃電）與彩虹。
- dist/city-world.js、combobox.js、panel-collapse.js：城市場景、通用下拉選單與面板縮小。
- dist/company-location.js、sky-model.js、sky-projection.js、sun-sky.js、moon-sky.js、moon-phase.js、sky-settings.*：公司所在地、日月天空與設定面板。
- dist/route-editor.*、route-curves.js、route-data.js、ufo-default-route.js：UFO 航線編輯與預設航線。
- dist/vendor/：固定版本 Three.js 0.180.0、SunCalc、Lucide 與各自授權。
- preview.mjs：只綁定本機的靜態預覽伺服器。
- scripts/：check-*.mjs 為驗證腳本，benchmark-sky-projection.mjs 為效能微基準。
- tests/browser/：瀏覽器端到端測試與框架。

## 驗證

```powershell
npm run verify
```

`npm run check` 對 dist/ 所有 JS 與 preview.mjs 做語法檢查；`npm run test` 執行 scripts/check-*.mjs；`npm run test:browser` 執行瀏覽器測試（較慢，需要 Edge 或 Chrome）。

## 天色與晨昏

設定公司所在地後，天色預設隨所在地的真實太陽高度連續變化：夜晚 → 黎明（粉橘）→ 白天 → 黃昏（橘紅）→ 夜晚。晨昏的時間由當天的日出日落自然決定，不使用固定時刻。即時模式與月亮、太陽預覽共用同一套天色計算，預覽某個時間點看到的天色，就是即時模式在該時間點的樣子。預覽播放在晨昏時會自動放慢，方便觀賞。

太陽是帶高光與邊緣暗部的圓潤球體加上立體短棒射線；月亮是有切面、球面明暗與固定隕石坑的球體（永遠朝向同一面），亮面形狀依月相計算。太陽、月亮與雲的前後關係是：太陽與月亮在最後方，雲在天際線後方，所以任何場景中的建築、樹木與地形都會遮住它們，雲也會遮住日月（太陽與月亮以最遠深度繪製；雲放在以鏡頭為中心放大 2.3 倍的群組中，外觀不變但位置遠在所有場景物件之後）。設定中的「天色隨所在地變化」可關閉；關閉後，或按右上角月亮／太陽按鈕，會改為手動切換日夜。未設定所在地時一律為手動。

## 天氣

設定公司所在地後，背景會依該地點的真實天氣變化（預設開啟，可在設定中關閉）：晴、多雲、陰、霧、毛毛雨、下雨、下雪、雷雨與大風。天氣資料來自 Open-Meteo（免金鑰），每 15 分鐘更新一次並快取在瀏覽器（同一次請求也取得三日預報與過去 6 小時降水）；查詢只送出四捨五入到小數 2 位的經緯度，不含任何金鑰或個人資料。網路失敗時會沿用最近一次資料（最久 3 小時），之後回到晴天，不影響工具入口。

天氣會與場景互相配合：雪地下雨會改為下雪，沙漠下雪會改為陰天；下雪時地面會逐漸變白，下雨時地面變濕、太陽與月亮變淡，大風會讓雲與滾草加快。雷雨閃光限制為每 5 秒最多一次，系統要求減少動態時不閃光、不顯示雨雪粒子。粒子數量隨畫質（輕量／均衡／精緻）調整。

設定中的「天氣預覽」可手動選擇任一天氣來檢視效果，只在本次瀏覽有效。商業或正式部署前，請確認 Open-Meteo 的使用條款是否符合貴公司的使用情境。

### 天氣詳情

標題列時間旁邊會顯示目前天氣與氣溫；點擊後展開詳情：濕度、風（含蒲福風級中文說明）、雲量、能見度、未來三天預報（天氣、高低溫、降雨機率）、更新時間與資料來源，並可立即更新。Esc、點擊外面或再按一次即可關閉。使用「天氣預覽」時，標籤會標示（預覽）並隱藏實際數據。升級前存下的舊天氣快取沒有預報資料，會被視為過期並立刻重新取得。

### 彩虹

雨停之後出現太陽時，天空的另一側會畫出彩虹（含較淡的副虹）。條件：過去 3 小時內下過雨（取自 Open-Meteo 的逐時降水）、現在沒有降水或雷雨、雲層沒有完全遮住太陽、太陽高度在約 1° 到 40° 之間（太高或在地平線下都不會出現），以及白天。彩虹的位置與太陽相對，弧線兩端被地面遮住，強度在雨後 90 分鐘內最強，之後逐漸淡出，3 小時後消失。「天氣預覽」中的「彩虹」會忽略太陽高度，方便檢視。

### 縮小面板

飛碟航線面板與日月升落預覽面板的標題列都有「縮小面板」按鈕：縮小後只保留標題、航線選擇與狀態（飛碟），或時間、滑桿與播放鈕（日月預覽），讓畫面上的軌跡不被面板遮住，仍可拖曳與預覽。每個面板各自記住縮小或展開的狀態。

## 城市場景

底部場景切換新增「城市」：粉彩積木街區、窗戶、路燈與天線。恐龍跑在深色柏油的雙向道路上，標線依台灣的慣例繪製：以全長的雙黃實線分隔對向車道（恐龍在黃線右側的第一條車道，靠右行駛）、白色虛線分隔同向車道、白色實線為邊線；每隔一段有斑馬線，兩個方向各在斑馬線前（依該方向車流的行進方向）畫白色停止線，兩條停止線之間不畫雙黃線與車道虛線，虛線也與斑馬線保持距離。兩側各有一條同向的雙車道道路，車輛沿著與道路相同的斜線行駛（右側道路與恐龍同向，左側道路迎面而來），同一條路上的車速度相同、等距排列，不會互相穿過。人行道與分隔島上不會有散落的地板方塊。路燈的光暈與標線留有高度差，不會因為共面而閃爍。夜晚窗戶與路燈會亮、地面出現光暈、車燈點亮；車輛數量依畫質與環境動態調整。手機上場景按鈕只顯示目前選中的名稱，其餘為圖示。

## 瀏覽器測試

```powershell
npm run test:browser
```

`tests/browser/` 的測試用 Edge 或 Chrome（無頭模式）操作真實頁面，不需安裝任何套件，也不連外網：框架會固定所在地與時鐘，並以假的天氣資料取代 Open-Meteo。可用環境變數 `BROWSER` 指定瀏覽器路徑，找不到瀏覽器時會自動略過。測試涵蓋天色與晨昏、預覽與即時一致、UI 漸變、天氣、彩虹、城市、下拉選單、面板動畫與各種視窗寬度，任何頁面 JavaScript 錯誤都會使測試失敗；失敗時的截圖在 `.test-output/`。可附上檔名關鍵字只跑其中一組，例如 `npm run test:browser -- rainbow`。

## 原型範圍

這版用於驗證構圖、操作與 3D 動態，不是公司正式入口。尚未串接公司登入、權限、工具真實資料或後台管理。地景比概念生成圖簡化，不承諾逐像素還原；持續動畫的流暢度需再於同仁實際設備上評估。

正式公司內部部署時，可將 dist/ 部署至公司靜態網站服務，再接公司現有身分驗證。此原型的私人預覽存取不等於公司 SSO。

## 海岸場景

底部的「海岸」按鈕會切換為沙灘、棕櫚與平靜海面；黑夜模式也會套用到海岸。設定中的自動輪換會依序走訪草原、沙漠、海岸、雪地、森林與城市。
